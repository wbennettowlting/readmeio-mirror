# OwlPay Harbor Docs

ReadMe documentation for OwlPay Harbor. Guides live in `docs/`, the API reference in `reference/`.

## Preview locally

From the repo root, run:

```sh
npx @readme/cli dev
```

This starts a local server so you can browse the docs and sidebar before pushing. To use a different port, add `--port <number>`.

> Note: the preview doesn't resolve `doc:` links, so they won't click through locally. They work on the live site.

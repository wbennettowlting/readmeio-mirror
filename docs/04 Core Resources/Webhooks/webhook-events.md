### Webhook Event Types

Harbor uses webhook events to notify your system in real-time when important status changes or activities occur in your account (such as customer verification updates or transfer state transitions).

To view the comprehensive list of supported webhook event types, their detailed descriptions, and trigger conditions, please visit our authoritative directory:

👉 **[List of Subscribing Events](https://harbor-developers.owlpay.com/docs/subscribable-events)**

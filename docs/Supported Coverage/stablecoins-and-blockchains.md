### Stablecoins

* **USDC** is supported on all blockchains listed below.
* **USDT** is currently supported on **Ethereum** only.

### Blockchains

Use the **Key** value in API requests, for example `"chain": "ethereum"`. In the Sandbox environment, transfers run on the testnet.

| Blockchain  | Key         | Confirmations | Approx. time | Mainnet           | Testnet (Sandbox) |
| :---------- | :---------- | :------------ | :----------- | :---------------- | :---------------- |
| Arbitrum    | `arbitrum`  | 65            | ≈20 seconds  | Arbitrum One      | Arbitrum Sepolia  |
| Avalanche   | `avalanche` | 1             | ≈2 seconds   | Avalanche C-Chain | Fuji              |
| Ethereum    | `ethereum`  | 12            | ≈3 minutes   | Ethereum Mainnet  | Sepolia           |
| Polygon PoS | `polygon`   | 50            | ≈2 minutes   | Polygon Mainnet   | Amoy              |
| Optimism    | `optimism`  | 65            | ≈20 seconds  | OP Mainnet        | OP Sepolia        |
| Base        | `base`      | 65            | ≈20 seconds  | Base              | Base Sepolia      |
| Arc         | `arc`       | 1             | ≈2 seconds   | Mainnet           | Testnet           |
| Stellar     | `stellar`   | 1             | ≈5 seconds   | Public Network    | Test Network      |
| Solana      | `solana`    | 1             | ≈5 seconds   | Mainnet           | Devnet            |

An on-chain transfer moves stablecoins from one blockchain address to another, including across blockchains.

| Type | Payment method |
| :--- | :--- |
| On-Chain | Blockchain ↔ Blockchain swap |


<br/>
On-chain transfers are available on all [supported blockchains](/docs/stablecoins-and-blockchains).

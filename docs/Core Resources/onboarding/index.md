To ensure security, legal compliance (KYC/AML), and standard-setting payment services, every customer using Harbor must go through our onboarding and verification process. 

Harbor handles the verification process securely in the background, validating profiles, storing documentation, and running AML/KYC checks. Once a customer is verified, they are cleared to execute transfers and operate wallets.

We support two onboarding methods, allowing you to choose the perfect balance between implementation speed and user experience control:

<Cards>
  <Card title="Onboard via Hosted Link" href="/docs/hosted-link-onboarding" icon="fa-link">
    **No-Code / Low-Code Integration**: Quickest to implement. Redirect users to Harbor’s secure hosted forms to sign agreements, fill out profiles, upload documents, and complete biometric checks.
  </Card>
  <Card title="Onboard via API" href="/docs/via-api" icon="fa-code">
    **Direct API Integration**: Total UI control. Collect customer profiles and documents directly inside your own application and submit them to Harbor in a single API payload.
  </Card>
</Cards>
